# Fill a Class Vacancy

Give the class coordinator a way to fill an available seat from the waiting list.
Move one waiting attendee to the enrolled list and return the selected attendee's
ID. Do not exceed the class capacity. If there is no seat or nobody is waiting,
leave the class unchanged and report that no attendee was promoted.

Waiting attendees can be regular or priority members. The coordinator wants the
promotion feature to work with both kinds of membership.
